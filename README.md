# Games

Browser games, playable from the menu page (`index.html`).

- **Four Rivers Gold** (`four-rivers-gold.html`): mahjong Four Rivers solitaire in 1930s Shanghai.
- **Regolith Runner** (`regolith-runner.html`): coin-op style lunar rover game.
- **Pebblebrook** (`pebblebrook.html`): a cosy 3D block world, built on three.js.
